Respuesta al ejercicio 1.3

Tecnología ¿Dónde y como se usaría en el contexto de los ejercicios 1.1 y 1.2?
HTTP Aunque el uso de HTTP sin cifrado no es recomendable para sitios gubernamentales; se podría utilizar quizás en entornos en los cuales la seguridad no sea un elemento crítico. Un ejemplo sería cargar información pública sobre trámites, o cualquier contenido estático, zonas públicas, etc, que no haya necesidad de trabajar con datos sensibles.
HTTPS Debería usarse en toda la pagina web por privacidad y seguridad, ya que, a diferencia del anterior, cifra la información transmitida entre el usuario y el servidor. Por ello es más recomendable justo en los casos donde se trabaja con información sensible, por ejemplo, en las zonas donde se solicitan certificados que hay que utilizar usuarios y contraseñas, certificados, claves pin.
HTML Es el lenguaje base de cualquier página web, determina TODA la estructura y contenido de todas las páginas de la web y donde se pueden enlazar con el resto de lenguajes para el resto de funciones como el CSS, PHP, JavaScript
PHP Usado en el backend para la gestión de procesos dinámicos. Podría utilizarse para gestionar las interacciones entre el usuario y la base de datos, como en el caso de consultar los registros de cotización, cálculo de pensiones o para procesar solicitudes de prestaciones, entre otras funciones ya descritas en otros apartados que también se pueden hacer.
CSS Se utiliza para mejorar la apariencia visual de toda la web, mejora la accesibilidad y usabilidad, se puede utilizar para dar un formato estándar a toda la pagina web y que haya un equilibrio.
SQL Sería la base de datos donde se almacena toda la información. Por ejemplo, cuando un usuario consulta su historial laboral, el sistema utilizaría SQL para extraer la información correspondiente desde una base de datos
JavaScript Se utiliza para mejorar la interactividad de la Web. En este caso también se puede usar para validar formularios, crear los gráficos de las cotizaciones, o incluso para contenidos dinámicos como un calendario de fechas para coger una cita.
